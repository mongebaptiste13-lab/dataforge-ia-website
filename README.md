# DataForge IA – Agency Website

Marketing website for DataForge IA, a data and artificial intelligence agency (AI automation, custom development, dashboards and data infrastructure). Content in French.

## Features

- Landing page: hero, clients, offers, how it works, metrics, pricing, security and FAQ sections with animated visuals
- Contact and careers pages with API routes sending emails through Resend
- SEO: per-page metadata, FAQ structured data (JSON-LD), sitemap, robots, Open Graph image, web manifest
- Legal notice page and responsive layout

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Radix UI · Resend · Netlify

## Getting started

```bash
pnpm install
pnpm dev
```

Environment variable: `RESEND_API_KEY` (email sending for the contact and careers forms).
